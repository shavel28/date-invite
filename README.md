# for you ♡

> a little interactive date invitation, made for someone special.

A small interactive website where every choice becomes part of the date.

Choose the place, pick the food, decide what to do after eating, and discover a little surprise at the end.

---

## ♡ the journey

```text
hello
  ↓
are you ready for a date?
  ↓
choose a place
  ↓
noodles or rice?
  ↓
choose your food
  ↓
what should we do after eating?
  ↓
walk / sit & talk / ride
  ↓
pick an activity
  ↓
a little surprise
  ↓
open the letter
  ↓
date receipt
```

---

## ✦ features

* Interactive date invitation
* Playful `NO` button
* Place selection
* Noodle / rice selection
* Food spot selection
* Activity selection
* Different activity branches
* Animated stars & soft effects
* Interactive envelope
* Personal letter
* Date receipt
* Print / download receipt
* Responsive for mobile & desktop
* Background music

## 🚀 run locally

```bash
git clone https://github.com/your-username/date-invitation.git
cd date-invitation
```

Then open `index.html` in your browser.

## ☁️ share

This is a static website, so it can be deployed with **GitHub Pages** or **Netlify**.

After deployment, you'll get a link that can be shared directly with anyone.

No installation needed.

Just open the link and start the journey.
